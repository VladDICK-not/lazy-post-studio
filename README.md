# Lazy-Post Studio 🚀

Профессиональная веб-студия для отложенной и мгновенной публикации новостей в **Telegram-канал** и **Threads**.
Стек на 100% бесплатен: **Next.js 14**, **Supabase (PostgreSQL + Storage)**, **Vercel** и **cron-job.org**.

---

## 🌟 Возможности

- **Визуальный WYSIWYG-редактор**:
  - Быстрое форматирование (жирный, курсив, зачеркнутый, ссылки, списки, цитаты).
  - Автоматическая адаптация: в Telegram уходит правильный HTML (`<b>`, `<a>` и т.д.), в Threads — чистый текст.
- **Управление лимитами Threads**:
  - Индикатор длины текста с предупреждением при приближении к 500 символам.
  - Возможность задать отдельный сокращенный текст специально для Threads в один клик.
- **Работа с медиа (изображениями)**:
  - Прямая загрузка фото с компьютера/телефона (сохраняется в Supabase Storage).
  - Или вставка прямой ссылки на картинку (URL).
- **Живой предпросмотр (Live Preview)**:
  - Режим Telegram: сообщение в точности как в канале (с бабблом, картинкой и форматированием).
  - Режим Threads: карточка поста с аватаром и счетчиком символов.
- **Гибкое планирование**:
  - Календарь с выбором точной даты и времени.
  - Быстрые кнопки пресетов: `+30 мин`, `+1 час`, `+3 часа`, `Завтра в 10:00`.
  - Кнопка **«Опубликовать сейчас»** для срочных новостей.
- **Очередь и история**:
  - Вкладки: Запланированные, Опубликованные, Ошибки.
  - Удаление и ручной повтор отправки при ошибке сети.
- **Личные уведомления в Telegram**:
  - Бот присылает вам в ЛС отчет об успешной публикации или детали ошибки.
- **Безопасность**:
  - Вход по мастер-паролю (без регистрации).

## 🛠 Пошаговая инструкция по запуску (10 минут)

### 1. База данных и хранилище Supabase (Бесплатно)
1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте новый бесплатный проект.
2. В боковом меню перейдите в **SQL Editor** и вставьте содержимое файла `supabase/schema.sql`, затем нажмите **Run**.
3. В **Project Settings -> API** скопируйте:
   - `Project URL` -> `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public key` -> `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `service_role secret` -> `SUPABASE_SERVICE_ROLE_KEY`

### 2. Подключение Telegram-канала
1. Откройте в Telegram бота `@BotFather` и отправьте `/newbot`.
2. Задайте имя бота и сохраните токен бота -> `TELEGRAM_BOT_TOKEN`.
3. Добавьте созданного бота в **Администраторы вашего канала** с правом публикации.
4. Укажите логин канала (например, `@my_news_channel`) или его Chat ID -> `TELEGRAM_CHANNEL_ID`.
5. Чтобы бот присылал вам в ЛС отчеты об отправке, узнайте свой личный Telegram ID (через бота `@userinfobot`) и впишите в `TELEGRAM_ADMIN_CHAT_ID`.

### 3. Подключение Meta Threads API
1. Зайдите на [developers.facebook.com](https://developers.facebook.com/) под своим аккаунтом.
2. Создайте приложение, подключите продукт **Threads API**.
3. В разделе **Threads -> Settings** добавьте ваш Threads-аккаунт как тестировщика.
4. В **API Explorer** сгенерируйте User Access Token с правами `threads_basic` и `threads_content_publish`.
5. Обменяйте его на долгоживущий токен (Long-Lived Token, 60 дней) и скопируйте в `THREADS_ACCESS_TOKEN`.
6. Ваш Threads User ID укажите в `THREADS_USER_ID`.

### 4. Развертывание на Vercel (Бесплатно)
1. Загрузите этот проект в свой приватный репозиторий на **GitHub**.
2. Перейдите на [vercel.com](https://vercel.com) и импортируйте репозиторий.
3. В разделе **Environment Variables** добавьте переменные из файла `.env.example`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `ADMIN_PASSWORD` (ваш пароль для входа на сайт)
   - `CRON_SECRET` (любая случайная строка для защиты триггера)
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHANNEL_ID`
   - `TELEGRAM_ADMIN_CHAT_ID`
   - `THREADS_USER_ID`
   - `THREADS_ACCESS_TOKEN`
4. Нажмите **Deploy**. Через 1 минуту ваш сайт будет доступен по ссылке `https://ваш-проект.vercel.app`!

### 5. Настройка бесплатного планировщика расписания
1. Зарегистрируйтесь на бесплатном сервисе [cron-job.org](https://cron-job.org/).
2. Создайте новую задачу (Cronjob):
   - **URL**: `https://ваш-проект.vercel.app/api/cron/publish?key=ВАШ_CRON_SECRET`
   - **Интервал**: каждые 2 или 5 минут (Execution schedule: Every 2 minutes).
3. Теперь cron-job.org будет автоматически вызывать ваш сайт, а сайт — публиковать все посты, для которых наступило время.

## 💻 Локальный запуск на компьютере

```bash
# 1. Установка зависимостей
npm install

# 2. Настройка переменных окружения
cp .env.example .env.local
# заполните ваши ключи в .env.local

# 3. Запуск dev-сервера
npm run dev
```

Сайт откроется по адресу: `http://localhost:3000`. Пароль по умолчанию: `admin123`.
